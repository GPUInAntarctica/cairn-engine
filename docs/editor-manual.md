# 编辑器手册 / Editor Manual

界面默认简体中文，可在 **文件 → 偏好设置** 中切换 English。

## 布局

```
┌──────────────────────────────────────────────────────────┐
│ 菜单栏  文件 编辑 资源 构建 窗口 帮助                          │
│ 工具栏  选择/移动/旋转/缩放 · 运行 暂停 单步 停止 · 视图选项     │
├─────────┬───────────────────────────────────┬────────────┤
│ 层级     │ 视口 / 代码 / 图像编辑器（页签）        │ 检视器       │
├─────────┴───────────────────────────────────┴────────────┤
│ 内容浏览器 · 控制台（底部页签）                                │
└──────────────────────────────────────────────────────────┘
│ 状态栏  场景 · FPS · Draw/Tris · 选中对象                     │
```

左右分隔条可拖拽调整宽度。

## 视口

| 操作 | 方式 |
| --- | --- |
| 旋转视角 | 按住右键拖动 |
| 平移 | 按住中键拖动 |
| 缩放 | 滚轮（正交模式缩放视口大小） |
| 飞行 | 右键按住后 WASD/QE，Shift 加速 |
| 选中 | 左键点击（自动上方形描边） |
| 移动/旋转/缩放实体 | 工具 W/E/R + 拖拽；Shift 吸附 |
| 聚焦选中 | F |
| 正交视图 | 工具栏立方体按钮 |
| Play 中操控 | 点击视口获得焦点，Esc 释放 |

## 快捷键

| 键 | 功能 |
| --- | --- |
| Ctrl+S | 保存场景 |
| Ctrl+O / Ctrl+N | 打开 / 新建场景 |
| Ctrl+B | 构建脚本 |
| Ctrl+P | 运行 / 停止 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做（整场景快照，100 步） |
| Ctrl+D | 复制实体 |
| Del | 删除实体 |
| Q / W / E / R | 选择 / 移动 / 旋转 / 缩放工具 |

## 工作流

### 创建实体
层级空白处或选中项右键 → **创建** → 图元（立方体/球/平面/圆柱/圆锥/圆环）、精灵、相机、灯光或空实体。

### 编写脚本
1. 内容浏览器右键 → **新建 C++ 脚本**（生成类骨架）
2. 双击脚本打开代码页签（Monaco，引擎 API 补全）
3. **Ctrl+B** 编译 —— 错误直接标注到代码行，控制台同步输出
4. 选中实体 → 检视器 → **添加组件 → Script** → 选择脚本类 → 字段即可编辑

### 图像编辑
双击纹理打开图像页签：图层、笔刷/橡皮/填充/直线/矩形/椭圆/取色、HSV + 色板、缩放适应。**生成法线贴图** 从亮度或 Alpha 生成切线空间法线（新图层），保存为 `*_normal.png` 后可在精灵渲染器中作为法线贴图使用（2D 光照生效）。

### 播放模式
**Ctrl+P** 运行：场景快照后启动脚本与物理；暂停/单步（工具栏或 Ctrl+P 切换）；**停止** 恢复进入时的场景快照。运行中的 `Debug::Log` 与音频事件实时回传编辑器。

### 导出 Player
**构建 → 导出 Player...** 生成可分发目录（项目 + 资源 + 编译好的玩法库 + 运行时），`npx electron .` 直接运行。

## 偏好设置

语言、C++ 编译器路径（默认取 PATH 中的 g++）、运行前自动保存、视口统计。存储于 `~/.cairn-engine/preferences.json`；最近项目同样保存在此。
